# 근무시간과 휴게시간은 어떻게 정해지나요?

# **청소년은 근무시간과 휴게시간이 법으로 정해져 있어요**

### 하루에 얼마나 일할 수 있나요?

청소년 근로시간은 다음과 같아요.

- 원칙: 하루 7시간 → 주 35시간
- 예외 (본인이 동의한 경우): 하루 8시간→ 주 40시간까지 가능

### 휴게시간은 꼭 받아야 하나요?

네, 반드시 받아야 해요.

- 4시간 근무 → 30분 이상 휴게시간
- 8시간 근무 → 1시간 이상 휴게시간

이 시간은 반드시 보장되어야 해요

### 휴게시간은 어떻게 사용하나요?

- 자유롭게 쉴 수 있어야 해요
- 일을 시키면 안 돼요

### 이런 경우 문제가 될 수 있어요

- 계속 일만 시키고 쉬는 시간을 안 주는 경우
- 휴게시간인데 일을 시키는 경우

→ 모두 법 위반이에요
