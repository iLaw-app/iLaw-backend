# 사이버폭력을 당했을 때 어떻게 대처하고 증거를 모아야 하나요?

# 감정적인 맞대응은 피하고 화면 캡처나 녹음 등으로 객관적인 증거를 확보해야 해요

## 올바른 대처 방법

- 가해자와 똑같이 욕을 하며 싸우거나 신상을 털어 공격하는 방식은 상황을 더 악화시킬 수 있으니 절대 하지 마세요.
- 출처가 명확하지 않은 메시지, 이메일, 채팅 신청은 열람하지 말고 바로 삭제하거나 답장하지 마세요.
- 낯선 사람이 직접적인 만남을 요구하면 절대 응하지 말고 부모님이나 선생님께 바로 알리세요.

## 증거 수집 가이드라인

- 게시글이나 댓글: 스마트폰 캡처나 컴퓨터 스크린샷 기능을 활용하세요.
- 작성자 특정: 상대방 ID, 게시 일시, 인터넷 주소(URL), 접속 IP 등이 잘 나오도록 캡처해야 해요.
- 영상물: 해당 영상을 휴대폰에 저장하거나 다른 기기를 이용해 동영상으로 녹화하세요.
- 통화 내용: 스마트폰의 녹음 기능을 활용하거나 스피커폰으로 통화하면서 다른 기기로 녹음하세요.
- 파일 관리: 캡처한 파일명에 일시와 장소를 적어두고 원본 파일을 안전한 곳에 따로 보관하세요.
